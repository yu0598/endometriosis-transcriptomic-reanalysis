# Core source references

- Tamaresis JS et al. Molecular classification of endometriosis and disease stage using high-dimensional genomic data. Endocrinology2014. PMID25243856; DOI[10.1210/en.2014-1490](https://doi.org/10.1210/en.2014-1490); [PMC4239429](https://pmc.ncbi.nlm.nih.gov/articles/PMC4239429/). GSE51981 cohort provenance.
- Bhat et al.2019, original GSE120103 study: [PMC6375207](https://pmc.ncbi.nlm.nih.gov/articles/PMC6375207/). Secretory eutopic endometrium/fertility strata; the array subset has36 profiles, not120 clinical participants.
- limma software DOI[10.18129/B9.bioc.limma](https://doi.org/10.18129/B9.bioc.limma). Installed implementation and reference versions are documented in SOFTWARE.md.
- The frozen source-based feature catalogue is represented by U/U2 with published symbols and supporting PMCID columns; these are a fixed targeted corpus, not a claim to a whole-field systematic review. The package reruns gene-level mean associations, not the original published diagnostic models.
