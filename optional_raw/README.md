# Optional upstream raw reconstruction (not self-contained)

The portable statistical rerun starts at the supplied exact gene matrices. It does not download raw files or repeat raw normalization. No raw tar, 36 FE gzip files, scanner images, whole R runtime, or annotation database is bundled.

`original_scripts/` contains the archived official download (120 and rawFE download), structural/identity inventory, and frozen128 preprocessing code. `source_manifests/` contains the original URLs, byte sizes, compressed/decompressed SHA256, 36-file identities and historical preprocessing manifest. Those historical manifests describe the original project; unshipped files listed there are **not** required by `scripts/run_all.R`.

Upstream data: [GEO GSE120103 raw archive](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE120nnn/GSE120103/suppl/GSE120103_RAW.tar), [official GPL6480 annotation](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL6nnn/GPL6480/annot/GPL6480.annot.gz). Download and verify every supplied original checksum before reuse. Do not repair GSM3393522/23: their public decompressed FEATURES tables are structurally incomplete, despite valid transport gzip files. The source-processed36 arm retains them; raw reconstruction admits34 only.

Personal absolute paths in historical textual records are redacted in this public edition; original package hashes remain recorded. Historical128 records the exact upstream method: gMedianSignal/gBGMedianSignal, ordinary finite spots, normexp/saddle/offset50, linear quantile followed by log2 with average-rank interpolation for ties, physical-spot mean per ProbeName, and mean/median across different ProbeNames mapped to a unique frozen current Entrez. Its statistical/preprocessing logic is preserved unmodified. It expects the documented historical relative source/metadata tree and the original project freeze inputs; it is an auditable upstream reconstruction recipe, **not a second one-command portable entrypoint**. Recreating that historical freeze requires the listed external raw/platform/source files, original directory layout and the recorded software. It was not rerun during this compact processed-input packaging test.

The compact package therefore makes a tested self-contained claim only for the processed-input statistical rerun (after installing R dependencies). It makes no raw-self-contained or raw-rebuild-tested claim. The source-processed GSE120103 baseline/export relationship remains unresolved.
